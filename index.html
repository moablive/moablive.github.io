AWLSRV LoginHub (IdP)

Enterprise Architecture

O que é este projeto?

Um sistema de Identity Provider (IdP) centralizado. Gerencia autenticação multi-tenant (múltiplas empresas), permissões de usuários e segurança via tokens JWT e master keys.

Projetado para ser a espinha dorsal de segurança de todo o ecossistema de aplicações da empresa.

Stack de Infraestrutura & Backend

Docker & Nginx

Orquestração de containers com proxy reverso e SSL.

Cloudflare Tunnels

Exposição segura sem abrir portas no firewall (Zero Trust).

PostgreSQL (ACID)

Transações manuais (commit/rollback) para integridade crítica.

Segurança

Autenticação híbrida (JWT + master keys) e hash bcrypt.
